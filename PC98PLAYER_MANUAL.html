1. PC98PLAYER とは

PC98PLAYER は、PC-9801 の本体・BIOS・MS-DOS の働きを自前で用意した小さな仮想 PC-98 です。 実機の ROM、フロッピーやハードディスクのイメージ、MS-DOS 本体は必要ありません。 ハードディスクにインストールした状態のゲームのフォルダに PC98PLAYER.EXE を置くだけで動きます。

  • 画面: テキスト画面・16 色グラフィック・GRCG・EGC・200 ライン表示
  • 音: FM 音源（PC-9801-86 / 26K 相当）、86 ボードの PCM、ビープ、MIDI（任意）
  • 文字: PC-98 の漢字 ROM の代わりに、Windows の MS ゴシックから字形を作ります（外字にも対応）
  • 入力: キーボード、マウス（バスマウス／マウスドライバ相当）
  • いつでも保存・再開できるステートセーブ

動作環境: Windows 10 / 11（64bit）。

2. はじめかた

  1. PC-98 のゲームを、実機やほかの環境でハードディスクにインストールした状態のフォルダを用意します（例: C:\PC98\DOUKYU2）。
  2. そのフォルダに PC98PLAYER.EXE をコピーします。
  3. PC98PLAYER.EXE をダブルクリックします。
    • 初回は PC98PLAYER.INI（設定ファイル）のひな形が作られ、起動するファイルの推測結果が表示されます。
    • 推測が違う場合や見つからない場合は、INI の Start= に最初に実行するファイル（.BAT / .COM / .EXE）を書いてから、もう一度起動してください。
[PC98PLAYER]
Start=NANPA2.BAT
ゲームに付属するインストール用・起動用のバッチファイル（GAME.BAT など）を Start= に指定すると、サウンドドライバの常駐なども含めて実機と同じ手順で起動します。

EXE を 1 つだけ置いて、全部のゲームで使い回す

PC98PLAYER.EXE を 1 か所（例: C:\PC98PLAYER\）に置いたまま、ゲームごとにショートカットを作って起動できます。

  1. 各ゲームのフォルダに PC98PLAYER.INI を置きます（無ければ初回起動時に作られます）。
  2. PC98PLAYER.EXE のショートカットを作り、プロパティの「作業フォルダー」にゲームのフォルダを指定します。
  3. そのショートカットから起動すると、作業フォルダーの PC98PLAYER.INI を読み、そのフォルダのゲームが動きます。

どのフォルダのゲームを動かすかは、次の順に決まります。

順番条件ゲームのフォルダ
1起動時の引数にフォルダか INI を指定したそのフォルダ（INI なら INI のあるフォルダ）
2作業フォルダー（カレント）に PC98PLAYER.INI がある作業フォルダー
3作業フォルダーに INI は無いが、実行ファイル（.BAT/.COM/.EXE）がある作業フォルダー（INI のひな形をそこに作ります）
4上のどれでもないEXE のフォルダ

INI の Start= が空のときは、ゲームのフォルダから起動するファイルを推測して起動します。見つからないときのエラーには、読んだ INI とゲームのフォルダの場所が表示されます。

INI に Root= を書くと、ゲームのフォルダを INI とは別の場所にできます（INI からの相対パスも可）。INI を 1 つのフォルダにまとめて管理したいときに便利です。

; C:\PC98\INI\DOUKYU2.INI
[PC98PLAYER]
Root=..\GAMES\DOUKYU2
Start=NANPA2.BAT

この場合はショートカットのリンク先を C:\PC98PLAYER\PC98PLAYER.EXE C:\PC98\INI\DOUKYU2.INI のようにします。

4. ステートセーブ／ロード

ゲームの途中でセーブできない PC-98 のゲームでも、その瞬間の状態をまるごと保存・再開できます。

  • Shift+F11 で画面が暗くなり、8 個のスロットが縮小画像つきで表示されます（F11 なら読み込み用の同じ画面）。
  • カーソルキーまたはマウスで選び、Enter か左クリックで決定、Esc・右クリック・F11 で取り消します。
  • 選択画面を開いている間、ゲームは止まっています。保存済みのスロットは上書きされます。
  • 保存先はゲームのフォルダの PC98PLAYER.SAV\SLOT1.P98S〜SLOT8.P98S です（1 個 約 1.4MB）。窓を閉じても残るので、次回起動後すぐに読み込めます。
注意: ステートセーブはゲーム本来のセーブの代わりにもなりますが、PC98PLAYER の版が大きく変わると古いステートを読めなくなる場合があります。大事な進行は、できるだけゲーム本来のセーブ機能でも保存してください。

4-2. 仮想フロッピー（キーディスク・インストール）

ゲームのフォルダは今までどおり A: として見せたまま、フロッピーディスクのイメージファイルを別のドライブ（既定は B:）に入れられます。

  • 使える形式: D88（.D88 .D68 .88D .D98）、ヘッダ無しのベタ（.HDM .XDF .DUP .TFD .2HD .IMG など。大きさで 1.25MB/1.2MB/1.44MB/640KB/720KB を判別）、FDI（Anex86）、NFD（T98-Next の r0・r1。NFDMAKE の -r1d で作った 3MB を超えるイメージも可）、フラックスイメージ（.SCP・.HFE。Greaseweazle などで磁気信号ごと吸い出したもの。読み込みのみ）。
  • 起動時に入れる: INI に FloppyImage=disk1.d88 と FloppyDrive=B を書きます（ファイル名はゲームのフォルダからの相対パスか、フルパス）。
  • 途中で入れる・入れ替える・取り出す: F11 または Shift+F11 の画面の下にある「FD B:」の欄から。F キー（または「入れる／実機…」ボタン）で出るメニューからイメージファイルや実機のドライブを選び、E キー（または「取り出す」ボタン）で取り出します。ディスクの入れ替えを求めるゲームやインストーラもこれで進められます。
  • マスターディスク（キーディスク）の確認: ディスク BIOS（INT 1Bh）で ID を指定したセクタの読み込み・READ ID などに応えます。イメージに記録されたセクタの ID・CRC エラー・デリーテッドデータ、NFD r1 に記録された READ DIAGNOSTIC（トラックをそのまま読む命令）の結果や、読むたびに内容が変わるセクタ（再試行データ）もそのまま返すので、プロテクトの情報まで記録されたイメージ（D88・NFD など）なら確認を通ることがあります。ベタ・FDI には特殊なセクタの情報が無いので、プロテクトつきのディスクは通りません。
  • キーディスクの確認で先へ進まないとき: Trace=1 にして PC98PLAYER.LOG を見てください。「[fd] セクタが見つかりません: C=07 H=00 R=4B N=02 …」のような行があれば、ゲームが確認に使う特殊なセクタがイメージに記録されていません（吸い出しのときに読み取れなかったもの）。PC98PLAYER 側では補えないので、別のドライブや別のモード（NFDMAKE なら -r1 と -r1d の両方）で吸い出し直し、その行のセクタが入ったイメージを使ってください。
  • DOS から: B:（FloppyDrive で指定したドライブ）のファイルを読み書きできます（FAT12/16）。INT 25h/26h（絶対ディスク読み書き）や、ボリュームラベルの検索（ラベル名でディスクを見分けるゲームがあります）にも応えます。
  • インストール: Start=B:\INSTALL.BAT のようにドライブ付きで書くと、そのドライブをカレントにして実行します。インストール先に A:（ゲームのフォルダ）を選べば、ゲームのフォルダへファイルがコピーされます。バッチの中で B: と書けばドライブも切り替わります。

例: 「転送元のフロッピーのドライブ名を引数で渡し、今いるドライブへ写す」インストーラ（スレイヤーズ！など）

[PC98PLAYER]
Drive=A
FloppyImage=SLAYERS_B.d88
FloppyDrive=B
Start=B:\INST.EXE
Args=B
CurrentDrive=A

ディスクの入れ替えを求められたら、F11 の画面でイメージを入れ替えてから Enter を押します。インストーラが COMMAND.COM /C COPY … のように呼ぶ内部コマンド（COPY・MD・DEL など）にも対応しています。

注意: フロッピーへの書き込みは、その場でイメージファイルへ書き戻されます（元に戻せません）。大事なイメージは先にコピーを取ってから使ってください。D88 の「書き込み禁止」が付いたイメージには書き込みません。 フォーマット（INT 1Bh の FORMAT）は、イメージと同じ形のトラックの中身を埋めるだけで、セクタの並びを変えることはできません。

4-3. 実機のフロッピードライブ（USB フロッピー・Greaseweazle）

イメージファイルの代わりに、パソコンにつないだ本物のフロッピードライブを仮想フロッピーのドライブ（既定は B:）として使えます。ディスクの中身は使うときにその場で読みます。

USB フロッピードライブGreaseweazle ＋ PC 用の FDD
読み方Windows のドライバ経由で「セクタ番号」で読む磁気信号（フラックス）をそのまま読み、PC98PLAYER が自分で復調する
普通のディスク（ファイルの読み書き・インストール）○（書き込みも可。下の注意を参照）○（読み込みのみ）
プロテクトつきの正規ディスク（キーディスクの確認）×（ID のずれたセクタ・CRC エラー等を扱えない）○（隠れたセクタ・CRC エラー・読むたびに変わるセクタ等もそのまま）
PC-98 の 1.25MB（2HD）3 モード対応のドライブだけ3.5 インチ・5 インチの 2HD ドライブ（回転数の違いは自動で合わせます）

つなぎ方

  • F11 の画面から: 「FD B:」の欄の F（「入れる／実機…」）のメニューに、見つかった USB フロッピードライブ（「USB フロッピー A:（1.25MB 対応）」など）と Greaseweazle が出るので選びます。ディスクを入れ替えたら、同じメニューの「読み直す」を選んでください（実機のドライブは入れ替えを自動では知りません）。
  • 起動時から: INI の FloppyImage= に次のように書きます。
    • FloppyImage=FDD:A … Windows のフロッピードライブ A:（\\.\A: とも書けます）
    • FloppyImage=GW … Greaseweazle（USB の ID で自動的に探します）。見つからないときは FloppyImage=GW:COM5 のようにポートを指定
  • Greaseweazle の設定: GWDrive=A（PC のケーブルのドライブ A / B。Shugart 接続なら 0 / 1 / 2）、GWRevs=3（1 トラックを何回転ぶん読むか。1〜8。多いほど読みにくいディスクに強く、遅くなります）。
  • イメージとして残す: メニューの「今のディスクを D88 で保存」で、実機のディスクを全トラック読んで D88 に書き出せます（ID・CRC エラー・デリーテッドデータは残ります。読むたびに変わるセクタは 1 回分だけ）。次からはそのイメージを使えば実機が要りません。
注意: ・トラックを初めて読むとき、USB フロッピーは 1 トラック 0.3 秒ほど、Greaseweazle は 1 秒ほど、ゲームが止まったように待ちます（読んだトラックは覚えておくので 2 回目からは待ちません）。
・USB フロッピーへの書き込みは、Windows からそのドライブを一時的に切り離せた（ボリュームをロックできた）ときだけ行います。できないときは書き込み禁止のディスクとして扱います。ドライブを開けないときは PC98PLAYER を「管理者として実行」すると開ける場合があります。
・Greaseweazle は読み込みだけです（書き込みは書き込み禁止として断ります）。セーブを書き込むゲームは、先に D88 で保存してからそのイメージで遊んでください。
・USB フロッピーでは、キーディスクの確認（特殊なセクタを読むもの）は通りません。プロテクトつきのディスクは Greaseweazle で読むか、NFDMAKE などで吸い出したイメージを使ってください。
・Windows の USB フロッピーのドライバが 1.25MB を読めない（3 モード非対応の）ドライブでは、1.44MB・720KB のディスクしか読めません。

5. 設定（PC98PLAYER.INI）

ゲームのフォルダの PC98PLAYER.INI をメモ帳などで編集します。文字コードは Shift_JIS・UTF-8 のどちらでも構いません。 ; から行末まではコメントです。書かなかった項目は既定値になります。

基本

Args=なしStart= に渡す引数。
Title=フォルダ名ウインドウのタイトル。

FakeDate=なし起動した日をこの日付としてゲームに見せます（例: FakeDate=1999/12/31）。以後は実際の時間どおりに進みます。FakeYear= より優先。

MidiSpeedFix=100MIDI の演奏速度（%、10〜1000）。「MIDI のときだけ曲が遅い」ソフトで 120〜150 などに上げます。MIDI ボードのテンポ機能で拍を刻むドライバ（MMD など）に効き、ゲーム本体の速さは変わりません。ゲーム側のタイマーで演奏するドライバには効きません。

6. 音源の設定

ゲームに付属のサウンドドライバ（PMD・MMD・PLAY5 など）は、バッチファイルに書かれたとおり本当に常駐して鳴ります。

  • 多くのゲームは起動時に音源ボードを自動で判別します。既定の SoundBoard=86 で、86 ボード用のドライバが選ばれるのが普通です。
  • 音が出ない・音が変な場合は SoundBoard=26 を試してください。26K 用の音で鳴ります。
  • ゲーム側で割込み番号（INT5 など）を設定する場合は、SoundIRQ= を合わせます（INT0=3、INT41=10、INT5=12、INT6=13）。
  • MIDI 対応のゲームで MIDI=1 にすると、ゲームが FM より MIDI を選ぶことがあります。Windows 標準の MIDI 音源は PC-98 当時の音源（SC-55 や MT-32）と音色が異なるので、FM で聴きたい場合は 0 のままにしてください。

7. メモリ（EMS／XMS）の設定

実機で CONFIG.SYS に HIMEM.SYS（XMS）や EMM386.EXE（EMS）を組み込んでいた状態を再現します。 ゲームの CONFIG.SYS に書かれていたドライバは読み込まれません。代わりに、この設定で同じ機能を用意します。

  • 多くのゲームはそのままで動きます。
  • EMS や XMS があると、それを使いに行く処理で落ちるゲームがあるかもしれません。その場合は EMS=0、XMS=0 を 1 つずつ試してください。
  • DOS エクステンダ（プロテクトモード）を使うゲームや、VCPI/DPMI を必要とするゲームには対応していません。

8. 動かないとき・落ちるとき

まず次の順に試してください。1 回に 1 項目ずつ変えて、どれで症状が変わったかを覚えておくと、原因の特定にとても役立ちます。

8-1. すぐにウインドウが閉じる

  1. ExitOnEnd=0 にして起動し直します。窓が閉じずに残るので、ゲームやバッチが最後に出したメッセージ（「メモリが足りません」「ファイルがありません」など）が読めます。
  2. Start= が正しいか確認します。インストール手順書で「〇〇.BAT で起動」とあるものを指定してください。
  3. インストールが済んでいるか確認します。フロッピーのままの内容では動かないゲームがあります。

8-2. 途中で落ちる・固まる・黒い画面のまま

順番INI に書く内容これで直った場合の原因
1FirstMCB=0100（次に 0400、0600 も）ゲームが、メモリ上の読み込み位置を前提にしている
2EMS=0EMS を使う処理
3XMS=0XMS を使う処理
4SoundBoard=2686 ボード（PCM など）を使う処理
5MouseDriver=0マウスドライバの有無の判定
6CpuMHz=8 または CpuMHz=33実行速度（タイミング）に依存する処理
7DOSVersion=3.30DOS の版の判定
直った設定はそのまま使い続けて構いません。その設定と、直った・直らなかったの結果を報告していただけると、ほかの利用者の役にも立ちます。

8-3. 日付がおかしい・2000 年以降だと動かない（2000 年問題）

1990 年代のソフトには、西暦を下 2 桁で扱っていて 2000 年以降の日付で誤動作するもの（年齢や経過日数の計算がおかしくなる、起動しない、セーブの日付が壊れる など）があります。INI で日付を 1999 年以前に見せかけると回避できます。

FakeYear=1998          ; 年だけ 1998 年にする（今日が 9 月 27 日なら 1998/09/27）
FakeDate=1999/12/31    ; 起動した日を 1999 年 12 月 31 日にする（翌日になれば 2000/01/01）
  • ゲームが DOS や BIOS から読む日付・曜日のすべてに効きます。
  • ファイルの日付も、見せかけた「今日」より新しいものは今日の日付として見せます（Windows 上の実際のファイルの日付は変わりません）。
  • 日付の書式は 1999/12/31・1999-12-31・19991231 のどれでも構いません。1980〜2099 年が指定できます。
  • FakeDate=1999/12/31 のまま日付をまたぐと 2000 年になります。長く遊ぶ場合は FakeYear= の方が安全です。

8-4. 画面がおかしい

  • 文字化け・字が欠ける: KanjiJIS=83 を試します。--fontsheet で字形の一覧を確認できます。
  • 縦縞や余計な模様が出る・一部が隠れない: 画面の組み合わせ（テキストとグラフィックの重ね方）の問題です。ステートセーブでその場面を保存し、スロットのファイルを報告に添えてください。
  • 動きが速すぎる／遅すぎる: CpuMHz= を調整します。

8-5. 音が出ない・おかしい

  • SoundBoard=26 と SoundBoard=86 を切り替えてみます。
  • ゲーム側の音源設定（「FM 音源」「MIDI」など）を確認します。ゲームの設定画面で「MIDI」が選べない（灰色になる）ときは、INI に MIDI=1 があるか確認してください。MIDI=1 のとき、MMD などのドライバが MIDI ボードを見つけられるようになります（例: 瑠璃色の雪は「設定」→「サウンド」で MIDI を選びます）。
  • Windows の音量ミキサーで PC98PLAYER がミュートになっていないか確認します。

9. トレース（記録）の取り方

原因の調査には、PC98PLAYER が内部で何をしていたかの記録（トレース）が役立ちます。

  1. PC98PLAYER.INI に次の 2 行を加えます。 
    Trace=1
ExitOnEnd=0
  2. PC98PLAYER を起動し、不具合が起きるところまで進めます。
  3. 終了すると、ゲームのフォルダに PC98PLAYER.LOG ができています（テキストファイル、UTF-8）。
  4. 調べ終わったら Trace=0 に戻してください（記録中は少し重くなり、ログも大きくなります）。

ログに書かれる主な内容

行の頭意味
[dos] 起動 …起動したプログラム名と、残りのメモリ量。
[dos] 常駐終了 …サウンドドライバなどがメモリに常駐した記録。
[dos] open …ゲームが開こうとしたファイル。
[dos] AH=xx -> error nnDOS の機能がエラーを返した記録（ファイルが無い、メモリ不足など）。正常な動作でも出ることがあります。
[dos] INT 21h AH=xxh 未対応PC98PLAYER がまだ対応していない DOS の機能をゲームが使った記録。重要な手掛かりです。
[io] in / out …対応していない周辺機器（I/O ポート）への読み書き。
[cpu] 未定義命令 …CPU が実行できない命令に出会った記録。多くの場合、その直前でメモリの内容が壊れています。
[shell] 見つかりません …バッチファイルが実行しようとしたプログラムが見つからなかった記録。

自分で見るときのコツ

  • 最後の方の行を見ます。落ちる直前に起動していたプログラムと、直前に出たエラーが原因の手掛かりです。
  • 未対応 や 未定義命令 があれば、ほぼそれが原因です。
  • open のあとに error 2 が続く場合は、ファイルが見つかっていません。インストール漏れやファイル名の違いを確認してください。

10. 不具合を報告するとき

次の情報があると、原因の特定がずっと早くなります。

  1. ゲーム名、発売元、版（CD 版・FD 版、HDD インストール版など）
  2. PC98PLAYER の版（配布ファイルの日付）
  3. 使った PC98PLAYER.INI の中身
  4. 症状（どの場面で・何をしたら・どうなったか）と、再現の手順
  5. 8-2 の表で試した設定と、それぞれの結果
  6. Trace=1 で取った PC98PLAYER.LOG
  7. できれば、不具合が起きる直前のステートセーブ（PC98PLAYER.SAV\SLOTn.P98S）
お願い: ゲームのファイルそのものは、著作権のため公開の場に載せないでください。ログとステートセーブのファイルだけで調査できることも多いです。

11. セキュリティソフトの警告

PC98PLAYER.EXE には電子署名がないため、Windows Defender などが「Trojan:Script/Wacatac.H!ml」のような名前で警告することがあります。 末尾の !ml は、既知のウイルスと一致したのではなく、機械学習による「怪しそう」という推定であることを示します。

  • PC98PLAYER はネットワークへの接続、ほかのプログラムへの干渉、キー入力の記録などは一切行いません。書き込むのは、ゲームのフォルダの中（ゲーム自身のセーブ、INI のひな形、ステートセーブ、ログ）だけです。
  • 配布元以外から入手した EXE は使わないでください。
  • 誤検知と判断される場合は、Microsoft の提出窓口（https://www.microsoft.com/wdsi/filesubmission）へ「誤検知」として報告できます。
  • 同梱のソースコードから Visual Studio でビルドした EXE を使う方法もあります。

12. 対応していないもの

  • フロッピーディスクからの起動（ブートディスクで動くゲーム）。フロッピーの FDC を直接操作するプロテクト（INT 1Bh を使わないもの）
  • 2 台以上のフロッピードライブを同時に使うこと（入れられるイメージは 1 枚。入れ替えは F11 の画面で）
  • DOS エクステンダ（プロテクトモード）を使うゲーム、Windows 3.1 用のソフト
  • 256 色表示（PC-9821 の PEGC）、31kHz 表示、N88-BASIC
  • ROM のグラフィック LIO（INT A0h-AFh）の描画機能。呼び出し口は用意してあり、呼ばれても止まらずに「正常終了」を返しますが、線や円などは描きません（Ray のように初期化だけ使うソフトは動きます）
  • ADPCM（スピークボード・ちびおと等）、MIDI のインテリジェントモードのうち、ボード側でトラックを演奏する機能（テンポ・クロック通知・MIDI メッセージの送出には対応）
  • ジョイスティック
  • CONFIG.SYS に書かれたデバイスドライバの読み込み（EMS・XMS・マウスは PC98PLAYER 側で用意します）

13. よくある質問

フロッピー版しか持っていません。

フロッピーのイメージ（D88 など）があれば、空のフォルダに PC98PLAYER.INI を置き、FloppyImage= に 1 枚目のイメージ、Start=B:\INSTALL.BAT（ゲームのインストール用のファイル）と書いて起動すると、そのフォルダ（A:）へインストールできます。2 枚目以降は F11 の画面で入れ替えてください（仮想フロッピー）。インストールが終わったら Start= をゲームの起動用のファイルに書き換えます。

ゲームのセーブデータはどこに保存されますか。

ゲームのフォルダの中に、実機と同じファイル名で保存されます。ステートセーブは別に PC98PLAYER.SAV フォルダへ保存されます。

1 つの PC98PLAYER.EXE で複数のゲームを遊べますか。

はい。ショートカットの「作業フォルダー」にゲームのフォルダを指定するだけです（はじめかたを参照）。

ゲーム中にメニューやステートセーブの画面が開きません。

マウスを捕まえている間も F11 / Shift+F11 は使えます。全画面の場合は Alt+Enter で窓に戻してからお試しください。
